# Tetris Game

This repository contains a simple Tetris game implemented in Python using Pygame.

## Requirements

- Python 3
- [Pygame](https://www.pygame.org/)

Install dependencies:

```
pip install pygame
```

## Run

Execute the game with:

```
python tetris.py
```

Use the arrow keys to move and rotate the blocks. Close the window or let the blocks reach the top to end the game.
